# GitHub Pages 구현 및 검증 계획

## 설계

사용자가 제공한 요구사항을 기준으로 기존 루트 Markdown을 VitePress의 소스로 직접 사용한다. 학습 콘텐츠와 파일명은 변경하지 않는다. 웹 전용 설정, 테마, 탐색 메타데이터는 `.vitepress`에 둔다. 웹 홈은 맵별 소개를 담은 `index.md`이며, README와 GUIDELINES는 웹 빌드에서 제외한다. 네 맵과 퀴즈·해설은 원래 파일명을 사용하는 독립 HTML URL을 갖는다.

검토한 대안은 (1) `vitepress-mermaid-viewer` 사용, (2) Mermaid와 별도 pan/zoom 라이브러리 조합, (3) 자체 뷰어 구현이다. 첫 번째는 요구된 제스처와 전체 화면·접근성 기능을 이미 제공하므로 우선 채택한다. 나머지는 연결 코드와 유지보수 범위가 늘어난다. 실제 화면 맞춤 동작을 확인하고 부족한 부분만 웹 테마에서 보완한다.

2026-11-25 npm 조회: 뷰어 0.5.2 (2026-10-21 배포), Node >=24, VitePress >=1, Mermaid >=10, Vue ^3. 안정 VitePress 1.6.4를 사용하고 직접 의존성과 lockfile을 고정한다.

## 검증 시 유의할 조건

- 공백과 대소문자를 포함한 파일명의 직접 URL과 새로고침.
- 기존 맵의 EOF로 끝나는 Mermaid fence 및 `<br/>`·이모지·중첩 subgraph.
- 긴 다이어그램의 최초 화면 맞춤, 100% 초기화, 확대 후 가장자리까지 이동.
- 모바일 세로/가로와 전체 화면에서의 도구막대 및 다이어그램 잘림.
- 다크 모드 재렌더링, 페이지 전환 후 이벤트·뷰어 정리.

기존 사용자 수정 `fisrt week/problem.md`는 유지한다. 모든 루트 학습 문서는 기존처럼 정적 공개 페이지가 되며 별도의 인증은 추가하지 않는다.

## 공개 범위 및 탐색 구조 변경

- 웹 공개 문서는 홈, 맵 4개, 퀴즈, 정답 및 해설의 7개로 구성한다. README와 GUIDELINES는 탐색뿐 아니라 직접 URL과 빌드 산출물에서도 제외한다. GitHub 저장소 원문 권한은 변경하지 않는다.
- 홈에는 맵별 소개와 학습 자료 링크만 제공한다.
- 학습 자료 아래에 `멘토링 1주차`를 두고 하위 항목으로 `퀴즈`, `정답 및 해설`을 배치한다. 원본 학습 파일은 변경하지 않는다.
- 아래 8개 문서 빌드 기록은 공개 범위 변경 전의 초기 검증 결과이다. 현재 빌드에서는 문서 7개와 404 페이지만 생성한다.
- 공개 범위 변경 후 전체 회귀 검사는 16 passed, 2 skipped. 최종 멘토링 하위 메뉴 구성 후 빌드를 다시 수행하고 공개 범위·메뉴 이동 검사 4개(데스크톱/모바일)를 재실행하여 모두 통과했다.

## 검증 결과 (2026-11-25)

- `npm run docs:build`: 성공. 기존 문서 8개 및 404 HTML만 생성. 테스트 결과 문서와 내부 설정 문서는 배포 대상에서 제외됨을 확인.
- `npm test -- --max-failures=1`: 12 passed, 2 skipped (각 환경에 해당하지 않는 마우스/터치 테스트만 제외). 데스크톱 1440×1000, Pixel 7 393×727, 화면 크기 변경 800×600 및 851×393.
- 네 맵 직접 URL, 실제 SVG·대표 라벨, HTML 라벨 높이, 전체 화면 열기·닫기, 확대·초기화·화면 맞춤, 콘솔 오류 없음 검증.
- 휠, 드래그 이동량, CDP 터치·핀치 확대 비율, 모바일 가로 화면, 시스템/버튼 테마 전환 및 사이드바 탐색 검증.
- VitePress 본문 줄 높이와 Mermaid 라벨 측정 차이를 테마에서 보정. 도구막대는 맞춤 영역과 분리.
- Obsidian 참고 이미지에 맞춰 neutral/classic 렌더링과 연회색 노드·얇은 테두리·그림자 없는 스타일 적용. 원본 Mermaid는 변경하지 않음.
- Mermaid 12에서 사용하지 않는 `debug` 사전 번들 힌트만 제거. 개발 서버의 DDIC SVG 렌더링 확인. 개발 모드 최초 진입에서 Chrome의 자동 `/favicon.ico` 요청 404는 관찰되었으나 정적 빌드에서는 favicon과 콘솔 검사가 통과함.
- 코드 리뷰 지적 사항인 테스트 산출물의 소스 탐색 제외를 반영. 별도 pan/zoom 의존성 없음.
- 원본 네 맵·GUIDELINES·실습/정답 파일에 새 내용 변경 없음. README 파일명 오타와 웹 운영 안내만 수정.
- 제한: 실제 모바일 기기 및 Safari 미검증. Mermaid의 큰 동적 청크에 대한 빌드 경고는 남아 있으며 빌드는 성공.
